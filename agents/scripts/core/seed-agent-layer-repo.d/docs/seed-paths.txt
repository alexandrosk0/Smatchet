# seed-paths.txt — the allowlist `git filter-repo --paths-from-file` keeps when
# seeding `the-unwilling-agentic-bunch` from a fresh Smatchet clone.
# Authored for plan `docs/plans/agent-surface-extraction-repo.md` rows 8/8c.
#
# CONTRACT (read before editing):
#   * Every non-`#` line is a filter-repo pathspec. There is NO inline-comment
#     form — a trailing `# why` becomes part of the path. Per-path rationale and
#     the publication verdict live in docs/seed-audit.md, never here.
#   * Matching is a PATH PREFIX rooted at the repo root, not a basename glob.
#     That is why the bare `AGENTS.md` line below takes only the root rulebook
#     and leaves every Source/Core/src/<ctx>/AGENTS.md host-side. The seed script
#     asserts that post-rewrite (`git ls-files '*AGENTS.md'` == `AGENTS.md`)
#     rather than trusting it.
#   * This is an ALLOWLIST, not a subtraction. `agents/` is deliberately NOT
#     listed as one prefix: that would sweep the project-scoped `agents/project/**`
#     straight into public history. The four portable subtrees are enumerated.
#   * The tests/bats block is GENERATED, never hand-edited:
#       grep -l 'agents/' tests/bats/*.bats | sort
#     seed-agent-layer-repo.sh phase 2 regenerates it and diffs against this file.
