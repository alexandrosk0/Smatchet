- 2026-06-20 · orchestrator (gate-escape postmortem, PR #1438) · [process] · P1 — an out-of-band PR-creation path (GitHub API / MCP `create_pull_request`, no local ship-loop) has no intent-capture step, so the PR body ships without a `## Intent` section and the block-allowlisted `Intent section` doc-validation check reds — then native GitHub auto-merge merges past it (`Intent section` is intentionally non-required per ADR-0022, so native auto-merge never consults the custom poller's block-allowlist). **Applied** — the preventing gate is the authoring-time rule that the implementer controls.
  Details: The ship-loop's intent capture (`capture-intent.sh` → `.session-intent/<branch>.log` → templated `## Intent`) runs only for PRs opened through the **local** ship-loop. A PR opened out-of-band via the API (the only path on a Claude-Code-web session with no local push to the live branch) has no mechanism to inject `## Intent`, so `Intent section` correctly reds; native auto-merge then merges past it because the check is deliberately non-required (ADR-0022, to avoid a merge_group deadlock) and GitHub-native auto-merge does not run `merge-gates.sh`'s block-allowlist. Promoting `Intent section` to a branch-protection required context is explicitly NOT the fix (ADR-0022).
  Preventing gate (applied): a rule in [`docs/agent-rules/ship-loops.md`](../../../agent-rules/ship-loops.md) § Intent capture — any agent calling the GitHub API/MCP `create_pull_request` MUST include a filled `## Intent` section (one-line redacted statement of the originating human ask) in the PR `body`, at authoring time. This catches the class (API-created PRs lacking intent) at the only point an agent controls when there is no local hook. The `Intent section` doc-validation check enforces it server-side.
  Cross-ref: postmortem [`postmortems.md`](../../postmortems.md) (2026-06-20 · PR #1438); ADR-0022 (intent-gate kept non-required); `.github/workflows/doc-validation.yml` (`Intent section` job); `agents/scripts/core/merge-gates.sh` (`MERGE_GATES_BLOCK_ALLOWLIST_RE` + `$intent` downgrade). Distinct from the 2026-06-19 #1428 escape (stale daemon allow-list) and the #1406/#1414/#1415 escape (non-poller merge path).
  Status: applied (the § Intent capture rule is in ship-loops.md and enforced by the `Intent section` check; residual hardening — making native auto-merge consult the block-allowlist — is bounded by ADR-0022 and tracked separately).
