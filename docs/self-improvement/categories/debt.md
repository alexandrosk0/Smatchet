- 2026-06-08 · grid-engine (via orchestrator) · [debt] · P2 — per-pane catalog VALUE-read routing blocked on per-context catalog POPULATION (multi-grid Slice 4 deferral)
  Details: Slice 4's plan called for routing each pane's cell-value / option-label / display-name resolution through ITS OWN `GridLiveContext::fieldCatalog`. Implementation was prototyped (`resolvePaneCatalog`, `GetPaneAvailableFields`, `ChoosePaneCatalogSource`) then REVERTED after review found the seam has no live data source: every catalog WRITE path (`SetFieldCatalog`, `ApplyStartupFieldCatalogSnapshot`, `SetAvailableUsers`, `HandleFieldCatalogError`) targets `fieldCatalog()` = the FOCUSED context. A non-focused CROSS-backend pane's context catalog is therefore never populated (only same-backend panes get the one-time seed copy in `EnsurePaneContextLive`; cross-backend panes "fill via the focused backend-switch catalog refetch" — i.e. only on focus). So routing would have (1) fallen back to the focused catalog for the cross-backend target case (rev 0) — a no-op — and (2) routed same-backend duplicate panes to their FROZEN seed copy, going stale whenever the focused catalog refetched — a regression vs the current shared-focused-catalog read.
  Concrete next action: populate each pane context's `fieldCatalog` independently first — seed cross-backend panes from the on-disk `FieldCatalogCache` snapshot for their backend at `EnsurePaneContextLive` (off-thread, mirrors the same-backend seed) and/or have the per-pane first-sync worker fetch the catalog into the pane's context (writing to the CONTEXT, not `fieldCatalog()`), with a per-context invalidation path so same-backend panes don't go stale. THEN re-land the read routing (`resolvePaneCatalog` + `ChoosePaneCatalogSource(paneFocused, paneCatalogRevision)`, resolve-once-per-pane, never per cell). This also requires the pane's endpoint config (Domain/PlaneUrl) to be available per-backend — verify the multi-backend config plumbing exists before fetching. Until then the user-visible "unfocused cross-backend pane shows raw field values until focused" defect remains (bounded: self-heals on first focus).
