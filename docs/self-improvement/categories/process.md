  Details: Driving a dual-target build, I ran the build piped through a trailing `grep`/`tail` to trim output; the pipeline reported success while the underlying `cmake` configure had actually FAILED. Under a non-`pipefail` shell a pipeline's exit status is the LAST command's (the `grep`/`tail`), not the producer's, so a real build/configure failure reads as exit 0 and the agent proceeds on a broken tree.
