Side note for whoever revisits this: the tests widen their wall-clock budgets on `__SANITIZE_ADDRESS__`, which clang-cl defines only from LLVM 22 (19.1.5 leaves it undefined under `/fsanitize=address`), so a clang-instrumented rig would also need a compiler-independent signal for those nine guards.
