# Ideas

`IDEA-NN` — proposals the user is **unsure** about, **not yet approved**. The upstream funnel: an
idea can't be promoted to a work item directly; on approval it **graduates** to
[BACKLOG.md](BACKLOG.md) — a move, not a copy: delete the `IDEA-NN`, repoint its cross-references to
the new `BL-NN`, no tombstone. Lifecycle and citation rules:
[work-items.md → Tracking](../agent-rules/work-items.md#tracking).

Entry shape: `- **IDEA-NN — <title>** — <one-liner>; <source (item / conversation / review)>`.
This ledger holds only **open** and **`Promoted → NN-slug`** entries — resolved ones are deleted.
